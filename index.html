PrimeAgentOrchestrator: Memory-Primed Agent Spawning

Spawns coding agents pre-loaded with memories from PostgreSQL + semantic search. Three generations of context delivery, four months of production use.

10 pages, 15-task precision study - Zenodo DOI 2026

Reminisce: Production Postmortem

The system scored 98.3% on direct single-session recall, then accumulated 77.2% noise across four months of production. Root-caused to a placeholder extractor marked "for testing," then retired.

98.3% peak on direct recall, 77.2% noise in production - Zenodo DOI 2026

Reminisce: A Cognitive Science-Inspired Memory Architecture for AI Agents

Architecture for persistent agent memory using keyword ranking and semantic consolidation. PostgreSQL + pgvector. Open source, MIT, 606 tests.

49.4-55.8% accuracy, ~81% precision on LongMemEvalS - Zenodo DOI 2026

DeadGraph: A Rights-Aware MCP Knowledge Base for Cultural Heritage Audio Collections

Rights-aware pipeline, 13 MCP tools, defense-in-depth hallucination prevention. 200-question benchmark with +60.1 point accuracy gain over raw LLM.
